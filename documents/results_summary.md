## 1. 概要

`research_plan.md` に定めたフェーズ0〜4を、ローカル環境(idsse-data 7試合、開発規模のグリッド解像度・サンプルサイズ)で一通り実施した。目的は、AD モデル(後述)の構造的限界(戦略的適応性の欠如)に対する**差分ゲーム**によるアプローチが、実データ上で成立する見込みがあるかを検証することである。

**結論を先に述べると**: 実現可能性は確認できた。捕捉可能集合(後述)は実際の守備成否に対して有意な予測力を持つ(AUC 0.745)。一方で、当初想定していた「HJIの軌道がADモデルより実軌道をよく説明する」という仮説はデータに支持されず、HJIの貢献は「軌道再現モデル」としてではなく「理論的な保証付き予測・準最適性の定量化」にあるという方向に研究の力点を修正する必要がある。準最適性指標の実装は完了したが、対称ゲーム設定に起因する退化により、現状の数値をそのまま解釈することはできない。

このドキュメントは、差分ゲーム理論に馴染みのない読者でも追えるよう、専門用語には初出箇所で簡単な説明を付し、巻末に用語集(2節)を置いた。

### スコープに関する注記

- 全て**ローカル(M-series CPU)・開発規模**での実行結果である。グリッド解像度・AD モデルのCOBYLA初期値数(N_INIT)・サンプルサイズは計算コストの都合で原著/本番設定より縮小している(詳細は各節に記載)。
- 全1,454件・本番解像度での実行は `research_plan.md` 4.5節の運用フローに従い、Colab側で行う想定であり未実施。
- 本ドキュメントの数値は、いずれも `documents/phase{0,1,2,3,4}_*.json` に保存された生データから再集計したものである。

## 2. 用語解説

本研究で使う専門用語を、以降の章を読む前に一通り確認できるようにまとめる。各節の本文でも初出時に簡単な補足を入れているが、詳細な定義はここを参照。

### 2.1 差分ゲーム・追跡回避ゲームに関する用語

| 用語 | 説明 |
|---|---|
| **差分ゲーム**(differential game) | 複数のプレイヤーが、連続時間で常微分方程式に従って動く状態(位置・速度など)を、それぞれ自分の行動(コントロール入力)で操作し合う動的なゲーム理論の枠組み。チェスのような手番制ゲームと違い、両者が同時進行的に、しかも物理法則(運動方程式)に縛られながら意思決定する。 |
| **追跡回避ゲーム**(pursuit-evasion game) | 差分ゲームの代表的な設定。一方のプレイヤー(追跡者・本研究では守備者)が他方(逃走者・攻撃者)を捕まえようとし、逃走者は逃げ切ろうとする、ゼロサム(一方の得は他方の損)構造のゲーム。本研究の1対1守備の数理的な土台。 |
| **ミニマックス構造**(min-max) | 「一方が最小化しようとし、もう一方が最大化しようとする」という差分ゲームの標準的な定式化。本研究では守備者が捕捉までの時間を**最小化**しようとし、攻撃者が同じ量を**最大化**(=できるだけ捕まらない)しようとする。$\min_{u_d}\max_{u_a}$ という記法はこれを表す。 |
| **最悪ケース**(worst case) | 「相手が、自分にとって一番都合の悪い行動を常に選んでくる」という仮定。例えば守備者から見ると、攻撃者がその瞬間その瞬間で最も上手く逃げる行動を選び続けたら、という前提を置く。ミニマックス構造(相手が自分の利益のために最善を尽くすという前提)から自然に出てくる考え方で、この仮定のもとで導かれる結果だからこそ「相手がどんなに賢く逃げても保証される」という強い意味を持つ。裏を返せば、実際の選手は最悪ケースほど完璧には動かないため、理論値(価値関数)と実際の結果はしばしば食い違う(7節の準最適性はこの食い違いを定量化するもの)。 |
| **Hamilton-Jacobi-Isaacs (HJI) 方程式** | 差分ゲームにおいて「両者が最善を尽くした場合に何が保証されるか」を特徴づける偏微分方程式。ミニマックス構造を持つ差分ゲームの理論(Isaacs, 1965)にちなむ。この方程式を解くことで、次に説明する「価値関数」が得られる。 |
| **価値関数** $V(x,t)$ | ある状態 $x$(本研究では攻撃者と守備者の相対位置・相対速度)から、残り時間 $t$ の間に両者が最適に行動した場合に保証される結果を表す関数。本研究では $V(x,t)\le0$ なら「守備者は時間 $t$ 以内の捕捉を保証できる」、$V(x,t)>0$ なら「保証できない」と定義した。 |
| **到達可能集合 / 捕捉可能集合**(Backward Reachable Set, BRS) | 価値関数が $V\le0$ を満たす状態の集合。「そこから出発すれば、相手がどんなに賢く逃げても(最悪の場合でも)、時間 $t$ 以内に目標(捕捉)を達成できる」という**理論的な保証**を持つ状態の集合。本研究の中心的な出力。 |
| **ダブルインテグレータ** | 加速度(コントロール入力)を直接操作し、それを積分して速度、さらに積分して位置が決まる、最も基本的な運動モデル(位置 → 速度 → 加速度、という2階の積分関係からこう呼ぶ)。ニュートン力学の「力 = 質量 × 加速度」に対応する単純化されたモデル。 |
| **捕捉半径** $r_{\text{capture}}$ | 攻撃者と守備者の距離がこの値以下になったら「捕捉成立」とみなす閾値。本研究では1.5mを採用。 |
| **コントロール / ディスターバンス**(control / disturbance) | ミニマックス構造の中で、最小化する側の行動(本研究では守備者の加速度)を「コントロール」、最大化する側の行動(攻撃者の加速度)を「ディスターバンス(外乱)」と呼ぶ。使用ライブラリ `hj_reachability` の命名規則に由来する用語で、どちらが「良い」「悪い」という意味はない。 |
| **準最適性**(Suboptimality) | 理論的に最適な(=価値関数が示す保証された)結果と、実際に観測された結果との差。選手が理論通りの最適戦略で行動していない度合いを定量化する指標。本研究では $\text{Suboptimality}=V^{\text{observed}}-V^*$ と定義した(6節参照)。値が正なら守備側が理論上の機会を活かせなかったことを、負なら攻撃側が理論上の最悪ケースほど上手く回避できていなかった(または運動能力の見積もりが実態と食い違っている)ことを示唆する。 |

### 2.2 AD モデルに関する用語

| 用語 | 説明 |
|---|---|
| **AD モデル**(Attacker-Defender model) | Brink et al. (2023) が提案し、Narizuka & Yamazaki (2026) が改良した、1対1ドリブル局面を記述する運動モデル。攻撃者・守備者それぞれに6個のパラメータ($f,\tau,\beta$ ×2名分)があり、これらを実際の軌道にフィットさせることで選手の動きを再現する。差分ゲームのような「理論的に最適な行動」を導出するモデルではなく、あくまで観測データに合わせてパラメータを調整する**記述的**モデルである点がHJIと対照的。 |
| **パラメータ $f,\tau,\beta$** | $f$: 駆動力の大きさ(どれだけ強く加速するか)。$\tau$: 速度が最大になるまでの時間定数(どれだけ素早く反応するか)。$\beta$: ゴール方向への志向と相手選手への反応のバランス(戦略配分)。 |
| **境界張り付き現象** | パラメータ最適化の結果が、設定した探索範囲の端(上限や下限)にちょうど張り付いてしまう現象。「本当はもっと極端な値が最適なのに、範囲の制約で妥協させられている」ことを示唆し、モデルの表現力の限界の兆候として注目される。 |
| **$\varepsilon_p$(誤差指標)** | AD モデル・HJIモデルいずれについても、モデルが生成した軌道と実際の軌道のズレを、実際の総移動距離で正規化した指標。値が小さいほど、そのモデルが実際の動きをよく再現できていることを意味する。 |

### 2.3 数値計算・統計に関する用語

| 用語 | 説明 |
|---|---|
| **COBYLA** | Constrained Optimization BY Linear Approximation の略。勾配(微分)情報を使わず、制約条件付きの非線形最適化を行うアルゴリズム。AD モデルのパラメータ推定に使用(原著論文と同じ手法)。 |
| **ラテン超方格サンプリング**(Latin Hypercube Sampling) | 多次元空間からできるだけ偏りなく複数の初期値候補を生成する手法。最適化は初期値によって結果(局所最適解)が変わりうるため、多数の初期値から試して一番良い結果を採用するために使う。 |
| **グリッド解像度・accuracy** | HJI方程式を数値的に解く際、状態空間を格子(グリッド)に区切って近似計算する。格子の細かさ(解像度)と、微分の近似精度(`accuracy`: low/medium/high等)が計算コストと精度のトレードオフになる。本研究のローカル実行は開発規模の解像度(31×31×21×21、accuracy=medium)を使用。 |
| **AUC**(Area Under the Curve) | 「捕捉可能」という予測の確信度でイベントを並べたとき、実際に捕捉が起きた事例と起きなかった事例をどれだけ正しく順序付けられているかを表す指標。0.5がランダムな予測と同等、1.0が完全な予測。 |
| **適合率**(Precision) | 「捕捉可能」と予測した事例のうち、実際に捕捉が起きた事例の割合。 |
| **再現率**(Recall) | 実際に捕捉が起きた事例のうち、「捕捉可能」と正しく予測できた事例の割合。 |
| **混同行列**(confusion matrix) | 予測(捕捉可能/不可能)と実際(捕捉された/されなかった)の組み合わせを、TP(正しく捕捉可能と予測)・FP(誤って捕捉可能と予測)・FN(捕捉可能を見逃した)・TN(正しく捕捉不可能と予測)の4通りに分類した表。 |
| **Wilcoxon符号順位検定** | 同じイベントに対して2つの手法(本研究ではADモデルとHJI)の誤差を比較するとき、その差の中央値が0と有意に異なるかを調べるノンパラメトリック(正規分布を仮定しない)統計検定。$p$値が小さいほど、2つの手法の性能差が偶然とは考えにくいことを示す。 |

| 項目 | 結果 |

| 1試合あたり平均 | 207.7件 |

## 4. フェーズ1: AD モデル Baseline 再実装

**目的**: Narizuka & Yamazaki (2026) の改良推定法(相手の実軌道を固定した独立最適化)をidsse-dataに再実装し、パラメータの境界張り付き現象が再現されるかを確認する。

原著論文(arXiv:2512.22596)本文を取得し、探索範囲・制約・最適化アルゴリズムを正確に再現した:
- 最適化アルゴリズム: **COBYLA**(2.3節)
- 初期値: ラテン超方格サンプリング(2.3節)($f\in[-11.3,11.3]$, $\beta\in[-5,5]$, $\tau\in[0.9,2.5]$)
- 制約: $\tau\ge0.9$、$\beta\in[-10,10]$、$|f\tau|\le10.2$
- 実装: `ad_drg/ad_model.py`(モデル・最適化)、`ad_drg/extraction.py`(軌道抽出)

計算コストの都合上、ローカルでは7試合×10件=70イベントをサンプリング(N_INIT=20、原著はN=100・全31,028件)して検証した。

| 指標 | idsse-data(本実装、n=70) | 原著(J1リーグ、n=31,028) |
|---|---|---|
| 採択率($\varepsilon_a<0.1$ かつ $\varepsilon_d<0.1$) | **92.9%**(65/70) | 88.5%(27,457/31,028) |
| 境界張り付き率(いずれかのパラメータ) | **49.3%** | 数値未報告(定性的に一致) |
| パラメータ別張り付き率 | f: 27.1%, τ: 21.4%, β: 1.4% | — |
| $\varepsilon_a$(誤差指標、2.2節) | mean 0.043 / median 0.025 | 未報告 |
| $\varepsilon_d$ | mean 0.032 / median 0.028 | 未報告 |

### 評価

- 採択率は原著と同水準(むしろ高い)。AD モデルの記述力自体は、異なるリーグ・データセット・トラッキングシステムでも十分再現された。
- 境界張り付き現象は明確に再現された。特に $f$(駆動力)・$\tau$(時定数)で顕著、$\beta$(バランス)はほぼ張り付かない。これは「戦略配分のバランス」よりも「駆動の強さ・反応速度」の推定でAD モデルが構造的な限界にぶつかっていることを示唆し、本研究の狙い(戦略的適応性の欠如)と整合する。
- **限界**: サンプル数70件(全体の4.8%)であり、原著の31,028件と比べて統計的な確度は低い。全数実行はColabでの本番実行が必要。

## 5. フェーズ2: HJI数値解法の実装

**目的**: `hj_reachability` による4次元ダブルインテグレータ動力学・捕捉可能集合(BRS、2.1節)の計算パイプラインを構築する。

実装: `ad_drg/reachability.py`(動力学クラス・グリッド構築・BRS計算)、`ad_drg/calibration.py`(外れ値除去込みキャリブレーション)。

### 実装中に発見・修正した2つの技術的問題

1. **時間方向の後処理漏れ**: `hj.solve` が返す生の価値関数(2.1節)は「時刻tちょうどに目標へ到達するための価値」を各時刻で独立に解いたものであり、時間方向に単調ではない(対称な加速度上限のケースで、時間が経つほど値が発散的に増加する現象を検証により確認)。「時刻t**以内**に捕捉可能」という意味論に合わせるには、時間方向の累積最小値(running minimum。各時刻の値を、それ以前の全時刻の値の最小値で置き換える処理)を取る後処理が必須であり、`solve_brs` に実装した。
2. **相対速度の境界設定ミス**: 状態空間の速度成分は攻撃者と守備者の**相対**速度 $\Delta v=v_a-v_d$ であり、個人の最大速度 $v_{\max}$ ではなく理論上その2倍まで到達しうる(正面から逆方向に走る場合)。グリッドの速度境界を $v_{\max}$ のままにしていたため、軌道シミュレーション中に相対速度が範囲外に出て補間計算がNaN(非数)を返す不具合があった。$v_{\text{bound}}=2v_{\max}$ に修正済み。

いずれも実装を進める過程で単体テストにより発見し、修正・再検証した(低解像度グリッドでは数値誤差(数値拡散)により捕捉可能集合が過小評価されることも合わせて確認)。

### キャリブレーション結果(外れ値除去後)

| 指標 | 中央値 | 95%ile | 99%ile | 最大値 |
|---|---|---|---|---|
| v_max [m/s] | 5.59 | **8.09** | 8.80 | 9.38 |
| a_max [m/s²] | 6.48 | **9.72** | 11.04 | 11.87 |

母数2,908件(選手×セグメント)中、除外されたのは速度27件・加速度42件のみ。フェーズ0(c)で見つかった巨大な外れ値(244 m/s等)は除去され、大部分のデータは物理的に妥当だった。以降のフェーズでは95%ile値($a_{\max}=9.72$, $v_{\max}=8.09$)を採用。

### 可視化結果とその解釈

攻撃者・守備者に同じ $a_{\max}$(**対称ゲーム**、つまり両者の運動能力が全く同じという設定)を与えて捕捉可能集合を計算したところ、相対速度ゼロの状態では捕捉可能領域が捕捉半径(1.5m)からほとんど拡大しなかった(`phase2_brs_slice.png`)。

これはバグではなく、**等能力の追跡回避ゲームに関するIsaacsの古典的な理論的結果**と整合する正しい挙動と判断した。直感的に言うと、追跡者と逃走者の運動能力が完全に等しい場合、逃走者は追跡者のどんな動きにも同じ大きさの反対の動きで対抗できてしまうため、最初から十分近くにいない限り理論上は永遠に捕まえられない(「引き分け」になる)、という古典的な結果である。非対称な加速度上限(defender有利)で検証したところ、期待通り捕捉可能領域が時間とともに拡大することを確認し、実装の妥当性を確認済み。

この結果は研究の狙いを支持する示唆でもある: 実際のサッカーでは守備者は頻繁にボールを奪うが、それは攻撃者が理論上の最悪ケース回避戦略で動いていないためであり、その乖離こそが7節(準最適性)が定量化しようとする対象である。

### 6.1 捕捉可能集合の予測精度(research_plan.md 5節②)

|---|---|

| 適合率(2.3節) | 0.450 |
| 再現率(2.3節) | 0.193 |
| **AUC**(2.3節) | **0.745** |
| 実際の守備成功率(base rate) | 0.211 |

**評価**: AUC 0.745 はランダム(0.5)を大きく上回り、捕捉可能集合には実際の守備成否を予測する有意な情報が含まれることを確認できた。ただし再現率は低い(19.3%)。これは対称ゲームの最悪ケースでは「捕捉可能」と判定される初期状態が非常に限定的なためで(5節の知見と整合)、実際の守備成功の多くは理論上の"保証された"捕捉可能集合の**外側**で起きている。

**outcomeラベルの限界**: 正式なタックル/インターセプトのイベントラベルではなく、次セグメントの保持チームによる近似であり、ファウルやアウトオブプレーを挟むケース等で誤ラベルが混入し得る。

### 6.2 AD モデルとの直接比較(research_plan.md 5節③)

7試合×10件=70イベントをサンプリングし、AD モデルとHJI最適軌道(HJIの価値関数から導かれる最適なフィードバック行動則を使い、相手の実軌道を固定して独立にシミュレーションしたもの。`ad_drg/hji_trajectory.py`)の再現誤差 $\varepsilon_p$(2.2節)を比較。

| | AD誤差平均 | HJI誤差平均 |
|---|---|---|
| 全体(n=58、HJI発散12件除外) | 0.033 | 0.511 |
| 境界張り付きサブセット(n=45) | 0.036 | 0.522 |

Wilcoxon符号順位検定(2.3節): いずれも $p<0.0001$ で **AD モデルの方が有意に誤差が小さい**。

**評価(重要)**: これは「AD の誤差が大きい局面でHJIの方が実軌道を良く説明できるか」という当初の仮説(1.3節)を**支持しない**結果である。境界に張り付いた事例に限定しても結論は変わらなかった。

理論的には妥当な結果と考えられる。AD はイベントごとにパラメータを自由にフィットさせる**記述的**モデルである一方、HJI は相手の実軌道を所与としても「最悪ケースを前提とした」パラメータフリーの**規範的**方策であり、実際の選手は最悪ケース最適で動いていないため、生の軌道再現という比較軸では構造的に不利だった(記述的モデル=データに合わせて自由に形を変える、規範的モデル=理論から導かれる「あるべき」行動、という違い)。

**→ 研究の主張の再整理**: HJI の価値は「軌道を良く再現する記述モデル」としてではなく、6.1節で示された「理論的な保証付き捕捉可能性の予測力」(AUC 0.745)と、7節の準最適性(理論値と実際の乖離の定量化)にあると位置づけを修正する。当初の狙い(1.3節)のうち①②寄りの主張はデータに支持され、③の「軌道再現でAD を上回る」という想定は支持されない。

## 7. フェーズ4: 準最適性の定量化

**目的**: $\text{Suboptimality}(x)=V^{\text{observed}}(x)-V^*(x)$(2.1節)を実装し、理論値と実際の選手行動の乖離を定量化する。

- $V^*(x)$: HJI価値関数(フェーズ2・3と同じ対称 $a_{\max}$ のBRS)。「理論上、最悪ケースでも保証される結果」を表す。
- $V^{\text{observed}}(x)$: 実際の観測軌道上で守備者が最も接近できた瞬間のコスト $\min_t\|p_a(t)-p_d(t)\|-r_{\text{capture}}$(outcomeラベルを介さず軌道から直接計算)。「実際に何が起きたか」を、$V^*$ と同じものさし(距離マイナス捕捉半径)で表したもの。

全1,448件の有効イベントで初期状態のSuboptimalityを計算。

| 指標 | 値 |
|---|---|
| Suboptimality 平均 / 中央値 | -2.94 / -2.23 |
| $V^*\le0$(理論上捕捉可能)の割合 | 9.0% |
| $V^{\text{observed}}\le0$(実際に最接近時に捕捉半径以内)の割合 | 39.2% |
| 守備側の非最適性($V^*\le0$だが未捕捉) | **0件(0.0%)** |
| 攻撃側の非最適性/制約誤り($V^*>0$だが捕捉半径以内まで接近) | 436件(30.1%) |

Suboptimalityが正の場合は「理論上は捕捉が保証されていたのに、実際には捕まえられなかった」ことを意味し守備側の非最適性を、負の場合は「理論上は捕捉が保証されていなかったのに、実際には捕まえられた」ことを意味し攻撃側の非最適性(または運動能力の見積もり誤り)を示唆する、という設計である(2.1節)。

### 評価(重要な限界)

「守備側の非最適性が0件」は字義通りには強い主張に見えるが、**対称ゲームBRSの構造的な退化が原因である可能性が高く、そのまま結論として採用すべきではない**。対称 $a_{\max}$ では捕捉可能集合($V^*\le0$)が捕捉半径(1.5m)のごく近傍にしか広がらないため(5節参照)、「$V^*\le0$」な初期状態はほぼ「最初から捕捉半径のすぐ近くにいる」状態と同義になり、$V^{\text{observed}}\le0$ を自明に満たしてしまう。加えて $V^{\text{observed}}$ は「最接近距離」に基づくプロキシであり、実際のタックル成立とは異なる概念である(この指標の"捕捉"率39.2%は、6.1節のoutcomeラベルベースの捕捉率21.1%よりかなり高く、この乖離自体がズレを裏付けている)。

**今後必要な改修**:
1. 攻撃者・守備者に別々の(非対称な)$a_{\max}$ を与えて捕捉可能集合を非退化にする
2. $V^{\text{observed}}$ をoutcomeラベル(実際のタックル/インターセプト成立時刻)に紐付けて定義し直す

現状の結果は「攻撃側の非最適性/制約誤り」の存在(30.1%)を示す一次的な証拠として位置づける。

## 9. 今後の課題

1. **非対称 $a_{\max}$ でのBRS再計算**: 攻撃者・守備者それぞれの個人別(またはロール別)キャリブレーション値を使い、対称ゲームの退化を解消する。フェーズ4の準最適性分析を意味あるものにするために必須。
2. **outcomeラベルの精緻化**: 現在は次セグメントの保持チームによる近似プロキシ。イベントデータ(ファウル・タックル等)との突き合わせ、または$V^{\text{observed}}$を実際の局面変化時刻に紐付ける改修。
3. **全1,454件・本番解像度でのColab実行**: フェーズ1(N_INIT=100)・フェーズ2〜4(高解像度グリッド)を計画通りColabで実施し、統計的な確度を上げる。
4. **AD モデルとの比較条件の再検討**: 6.2節の結果を踏まえ、HJIをそのまま「軌道再現モデル」として比較するのではなく、捕捉可能性の予測力・準最適性という軸での比較にウェイトを移す。
5. **「1対1ドリブル」の抽出基準の妥当性**: トラッキングデータのみからの独自再構成(ボール保持セグメント)である点、および基準(iii)「5m」の解釈(経路長 vs 変位)が原著と一致するかの確認。
